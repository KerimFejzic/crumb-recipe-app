# Crumb - Personal Recipe Book

Crumb is a mobile app that lets users save and organize their personal recipes. Users can add photos, ingredients, and instructions, and find their recipes by category or search.

Built with **React Native, Expo SDK 58, and TypeScript**.

## Run the project

```bash
npm install
npx expo start
```

Open the QR code in Expo Go. You may need to log in to the same Expo account on your computer and phone.

## Features

- [x] Typed Recipe model and mock recipe data
- [x] Recipe cards with images and press feedback
- [x] Home recipe list with search and category filtering
- [x] Reusable recipe details component (not linked to navigation yet)
- [ ] Login and sign up with Supabase
- [ ] Recipe detail route and tabs
- [ ] Add / edit / delete recipes with form validation
- [ ] Favorite toggling and saved recipes tab
- [ ] Camera/image picker for recipe photos
- [ ] Local preferences, backend database, and production build
- [ ] Light/dark theme and responsive layout

**Current milestone:** Lab 4 first screens. Tapping a recipe card logs its ID to the development console; navigation is scheduled for a later lab.
